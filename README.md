# Cosmic Launcher

Minecraft Launcher + FPS-Boost Client (Tauri v2 + React + Three.js).

## Trạng thái
- Windows / macOS / Linux: chạy được Minecraft Vanilla (tải bản từ Mojang, tự tải Java từ Adoptium).
- Fabric / Forge / NeoForge / Quilt, mod, skin, AI auto-fix: chưa làm.
- Android / iOS: mới có giao diện, chưa chạy được game.

## Xem giao diện nhanh
    npm install
    npm run dev

## Build bằng GitHub
1. Đẩy toàn bộ thư mục này lên một repo GitHub (nhánh main).
2. Tab Actions -> Build Windows / macOS / Android / iOS -> Run workflow.
3. Tải file ở mục Artifacts.
